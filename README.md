# IdealConstruction

Static website for **SICG, LLC** (SETX Ideal Construction & Remodeling) — residential and commercial construction in Southeast Texas (Beaumont area).

Rebuilt from the [archived site](https://web.archive.org/web/20240726135445/http://www.idealconstruction.group/).

## Local preview

Open `index.html` in a browser, or:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`

## GitHub Pages

Push to GitHub, enable Pages on the `main` branch (root), and the site will be live at:

`https://<username>.github.io/IdealConstruction/`

## Customize

- Update contact email in `index.html` (`info@idealconstruction.group` is a placeholder)
- Replace project placeholder images in `css/style.css` with real photos
- Add phone number when available
